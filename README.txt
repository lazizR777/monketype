Neon Typing Test
================
Ishga tushirish: index.html faylini brauzerda oching (qo'shimcha o'rnatish kerak emas).

Fayllar:
  index.html - sahifa tuzilishi
  style.css  - dizayn (neon uslub, mavzular, klaviatura, o'lchagichlar)
  script.js  - mantiq (so'zlar, sozlamalar, statistika, klaviatura)

Eslatma: shriftlar (Orbitron, Exo 2) Google Fonts'dan yuklanadi, internet bo'lmasa oddiy shrift ishlaydi.
Tab yoki Esc - testni qayta boshlash.
